# Glow 0.8.9

First public source release of **Glow (Codex Neon Appearance Plugin)**, created by **Logan Voss + Astra 6 Ultra**.

A soft, animated border integrated into the local app's **Settings → Appearance → Glow** panel. Includes Pulse, Bloom, and Ping; Soft and Neon palettes; single-color selection, palette browsing, and shuffle; and six material controls. Light and dark profiles stay synchronized with Appearance and preserve independent tuning.

[Watch the demo](https://www.youtube.com/watch?v=H-9Ug0_luwg) · [Install](https://github.com/LoganVoss/Glow#install-with-one-prompt) · [Refresh after updates](https://github.com/LoganVoss/Glow#after-an-app-update)

## Availability

Experimental, source-only release for Apple silicon Macs and reviewed app builds **26.1007.30912 (20156)** and **26.1007.21159 (20052)**. Requires your own valid Apple-issued signing identity. Unknown app versions stop without modification. Updates may replace Glow; run Refresh once support is available. No OpenAI application bundle is distributed.
